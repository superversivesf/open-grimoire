# rpg-master

Self-hosted RPG manual query engine. Upload PDFs, process into tiered
markdown, ask conversational questions answered by a local LLM via Ollama.

See the design spec: [docs/superpowers/specs/2026-08-02-rpg-manual-query-design.md](docs/superpowers/specs/2026-08-02-rpg-manual-query-design.md)
